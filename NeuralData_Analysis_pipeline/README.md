# NeuralData_Analysis_pipeline

This folder contains Jupyter notebooks used to preprocess and analyze neural activity data for the whole-brain learning paper. Run the notebooks in order (00 --> 08) to reproduce the full pipeline.

## Quick Start

```bash
# 1. Create and activate a Python 3.11+ environment (required by CeDNe; <3.13)
python3.12 -m venv venv
source venv/bin/activate   # macOS/Linux

# 2. Install dependencies
pip install -r ../requirements.txt

# 3. Install CeDNe (required by all notebooks)
pip install git+https://github.com/sahilm89/CeDNe.git@main

# 4. Launch Jupyter
jupyter notebook
```

## Data Setup

**Demo data (included in this repo):** Decompress `sampled_imaging_part1.zip`, `sampled_imaging_part2.zip`, and `sampled_behavior_data.zip` in the repository root folder, then run the notebooks. Both imaging zips extract into the same `sampled_imaging/` directory.

```
whole-brain-learning-paper/
```

## Notebooks

| # | Notebook | Description | Paper Figures |
|---|----------|-------------|---------------|
| 00 | `00-make_pickle_from_raw_data` | Import raw experiment files (csv/xlsx), parse metadata, and save cleaned datasets as `.cedne` pickle files. | — |
| 01 | `01-left-right-differences` | Compute left-vs-right differences in neural data; produce summary statistics and visualizations for lateralized activity. | — |
| 02 | `02-promoter-positions` | Analyze promoter/marker positions across samples. Uses CeDNe to create anatomical layouts for recorded neurons. | Fig. 1d |
| 03 | `03-heatmaps` | Generate activity heatmaps and test neural activation upon odor stimulation. | Fig. 1f,g; Ext. Data Fig. 3, 4a–c,j,k; Supplementary Fig 1,2 |
| 04 | `04-Complete-Tensors-...` | Build complete data tensors from partial observations via filtering, wavelet denoising, and imputation. | — |
| 05 | `05-Temporal-Components` | Extract Temporal Components (SVD), visualize neuron scores, fit a Linear Dynamical System, and save TCs. | Fig. 2a–d; Ext. Data Fig. 5a–h |
| 06 | `06-dropletassay-eccentricity` | Analyze worm body eccentricity from droplet-assay data and compare behavioral traces to neural Temporal Components. | Fig. 2e,f |
| 07 | `07-Neural-components-geometry` | Extract Neural Components (SVD along neuron dimension), visualize loadings, variance explained, and geometric changes with learning. | Fig. 5a,b; Ext. Data Fig. 10a–c; Supp. Fig. 9; Supp. Data 2 |
| 08 | `08-control-theory-framework` | Apply control-theory analyses to neural dynamics to identify fixed points. | Fig. 5c,d; Ext. Data Fig. 10d,e |

## Notes

- **Order**: Run notebooks in numeric order when reproducing the full pipeline; earlier notebooks prepare inputs for later ones.
- **Expected output**: Each notebook produces inline figures similar to those in the paper (see Paper Figures column above). Intermediate data files (`.cedne` pickles, `.pickle` tensors) are saved to `pickles/` and `processed/`. *These are produced from demo data which is a subset of the full dataset, so the figures will not be the same as those in the paper.*
- **Expected run time (demo)**: ~15–30 minutes total for all 9 notebooks on a standard laptop (Apple M1/M2 or comparable x86 CPU, 16 GB RAM) using the demo dataset. Individual notebooks take ~1–5 minutes each.
